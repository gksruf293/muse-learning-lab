AI는 영상 본편을 시청하지 않았습니다. 공개 소개·목차를 참고해 별도 예제·요청문·평가 기준을 직접 작성했습니다. 영상 요약이나 원강의 공식 평가 문항으로 표시하지 않습니다. 별점·수강평은 변동 정보이며 레슨 내용의 정확성을 보증하지 않아 학습 평가에 사용하지 않았습니다.

각 레슨은 준비5분, 자료 읽기 또는 선택 시청20분, 실습20분, 질문15분입니다. 영상 전체 수강은 별도 시간입니다. 계정이나 영상 접근이 없으면 공개 자료 및 [Claude Code 공식 지침](https://code.claude.com/docs/en/best-practices)을 읽고 같은 별도 실습을 진행할 수 있습니다. 강의 무료 여부와 AI CLI 로그인·사용 비용·한도는 별개입니다.

제출할 것은 시청 완료 체크가 아니라 본인이 고친 요청문, 실제 산출물, 확인한 결과와 미확인 사항입니다. 프로젝트 복사본 또는 가상 데이터로 연습하며 실제 사용자 답변·경력·성과를 생성하지 않습니다.
