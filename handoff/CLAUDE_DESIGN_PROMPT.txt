Muse 학습 블로그의 디자인과 사용성을 개선해 줘.

먼저 https://github.com/gksruf293/muse-learning-lab 의 README.md와 handoff/CLAUDE_DESIGN_CONTEXT.md를 읽고 현재 구현을 직접 실행해 봐. 로컬 폴더는 C:\CV\muse-learning-lab이야.

이 사이트는 무료 공식 문서를 하루 60분씩 읽고 실습한 다음, 이해 확인 질문에 내가 직접 답하고 ‘그날의 학습 완료’를 누르면 답변을 GitHub에 저장하고 PC의 Claude/Codex CLI가 리뷰하는 학습 블로그야. 학습 자료·완료 답변·리뷰는 모두 공개야. 리뷰는 OpenRouter나 별도 모델 API 대신 PC CLI로 실행하고, GitHub CLI가 기록을 저장해. GitHub Actions는 검사와 Pages 배포만 맡아.

기능은 보존하면서 한국어 읽기·답변 작성·나중에 복습하기에 좋은 디자인으로 완성해 줘. 본문 읽기 폭, 한글 타이포그래피, 코드 가독성, 모바일에서 긴 답변 쓰기, 문서·질문·리뷰 사이의 흐름을 우선해. 색과 스타일은 제안해도 돼. 현재의 기본 디자인을 그대로 따를 필요는 없어.

초안의 기기 저장, GitHub 공개 저장, 리뷰 대기/완료를 혼동하지 않게 해 줘. PC가 꺼졌거나 CLI 사용 한도에 걸리면 리뷰가 즉시 나오지 않는다는 실제 동작을 유지해. 공개 페이지에서 GitHub 최종 저장을 해야 하는 단계와 긴 답변의 다운로드 대체 흐름도 보존해. 실제 학습 기록이나 답변·점수를 지어내서 넣지 마.

주로 docs/index.html, docs/assets/style.css, docs/assets/app.mjs의 렌더링, docs/guide.html을 수정해 줘. JSON 학습 자료와 GitHub payload/댓글 표시 형식, 보안 경계는 유지해. 필요하면 구조를 개선하되 이유와 기존 기능 보존 방식을 설명해 줘.

계획이나 시안만 제시하지 말고 실제 코드를 수정하고 실행해. npm test와 npm run check를 통과시키고 데스크톱·모바일 실제 화면, 키보드 포커스, 답변 초안 복원, 공개 저장, 리뷰 표시를 확인해 줘. 완료 후 변경 파일, 검증 결과, 남은 제한을 알려 줘.
