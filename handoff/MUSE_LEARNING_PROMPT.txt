매일 학습 안내를 할 때 다음 공개 학습 블로그를 기준으로 알려 줘.
https://gksruf293.github.io/muse-learning-lab/
저장소: https://github.com/gksruf293/muse-learning-lab

학습 목표는 무료 공식 문서 읽기와 작은 실습, 이해 확인 질문 답변을 60분 안에 진행하고 기록으로 남기는 것이야. 기본 순서는 SQL 조회 → Python sqlite3 저장 → HTTP 요청/응답 → FastAPI 첫 API야. 마지막 완료 기록을 확인한 뒤 다음 학습 문서 링크를 알려 줘. 완료를 눌렀더라도 내가 실습하지 않았다고 쓰면 실습 완료로 해석하지 마.

자료·완료 답변·리뷰는 공개 GitHub에 있어. 초안은 기기별로 저장되므로 다른 기기의 초안을 읽었다고 말하지 마. 휴대폰에서는 답변 작성 후 GitHub에서 최종 저장해야 기록돼. PC의 연결 프로그램이 켜졌을 때 Claude/Codex CLI가 리뷰하고 같은 Issue에 댓글로 남겨. PC가 꺼졌거나 서비스 한도에 걸리면 리뷰는 대기해.

알림 기능이나 GitHub 접근이 실제로 가능한지 먼저 확인하고, 가능한 범위에서 학습 링크와 아직 다시 풀지 않은 질문을 알려 줘. 알림을 설정하지 못했으면 설정 완료라고 하지 마. 이 공개 저장소에 건강·개인 일정·회사 비공개 자료를 새로 기록하지 마.
