학습 화면과 PC 연결

자료·답변·리뷰는 공개 GitHub 저장소에 남습니다. AI 리뷰는 PC의 Claude 또는 Codex CLI가 작성하고, GitHub CLI가 저장합니다. 별도 모델 API 키는 사용하지 않습니다. CLI에 로그인한 계정의 사용 한도는 적용됩니다.

PC에서 시작하기

  1. 저장소를 PC에 받습니다.
  2. Node.js 22 이상, GitHub CLI, Claude Code 또는 Codex CLI를 준비합니다.
  3. gh auth login과 사용할 AI CLI 로그인을 완료합니다.
  4. PowerShell에서 ./start-local.ps1을 실행합니다.
  5. PC용 학습 화면을 엽니다.

이 PC의 설치 경로는 실행 스크립트가 자동으로 찾아 사용합니다. 공개 페이지가 PC 화면을 여는 권한을 주지 않거나 PC 프로그램이 꺼져 있으면 위 주소를 새 탭에 직접 여세요.

완료 버튼을 누르면

  1. 현재 기기의 답변 초안을 확인합니다.
  2. PC 연결 프로그램이 GitHub CLI로 공개 학습 Issue를 만듭니다.
  3. 연결 프로그램이 Claude/Codex CLI에 학습 자료·평가 기준·답변을 전달합니다.
  4. 리뷰를 같은 Issue 댓글로 저장합니다.
  5. 학습 기록을 새로고침하고 펼치면 답변과 리뷰를 다시 볼 수 있습니다.

휴대폰과 공개 페이지

공개 페이지에서는 답변 작성 뒤 GitHub의 최종 저장 버튼을 눌러야 기록됩니다. PC가 꺼져 있으면 리뷰는 대기합니다. PC 연결 프로그램을 다시 켜면 남은 기록을 처리합니다. GitHub 저장 전의 초안은 다른 기기에 자동으로 공유되지 않습니다.

문제가 생겼을 때

로그인이 풀리거나 CLI 사용 한도에 도달하면 답변은 보존되고 리뷰만 대기합니다. PC 연결 화면의 상태와 콘솔 메시지를 확인하세요. 즉시 리뷰가 필요하면 답변 아래 ‘수동 리뷰 프롬프트’를 복사해 AI 대화에 전달할 수 있습니다.
