학습 화면과 PC 연결

자료·답변·리뷰는 공개 GitHub 저장소에 남습니다. AI 리뷰는 PC의 Claude 또는 Codex CLI가 작성하고, GitHub CLI가 저장합니다. 기본 도구는 Codex입니다. 별도 모델 API 키는 사용하지 않으며, CLI에 로그인한 계정의 사용 한도가 적용됩니다.

답변이 거치는 세 단계

학습 화면의 완료 막대 아래에 같은 세 단계가 표시됩니다. 각 단계는 따로 끝납니다.

  1. 기기 초안입력할 때마다 현재 브라우저에 자동 저장됩니다. 다른 기기와 동기화되지 않고, 아직 공개되지 않았습니다.
  2. GitHub 공개 저장PC 화면에서는 완료 버튼이 바로 저장합니다. 공개 페이지에서는 GitHub 화면의 생성 버튼을 직접 눌러야 저장됩니다.
  3. PC CLI 리뷰GitHub에 저장된 답변만 리뷰합니다. PC 연결 프로그램이 켜져 있어야 하며, 끝나면 같은 기록의 댓글로 남습니다.

PC에서 시작하기

  1. 저장소를 PC에 받습니다.
  2. Node.js 22 이상, GitHub CLI, Claude Code 또는 Codex CLI를 준비합니다.
  3. gh auth login과 사용할 AI CLI 로그인을 완료합니다.
  4. PowerShell에서 ./start-local.ps1을 실행합니다. Claude를 쓰려면 ./start-local.ps1 -Provider claude를 실행합니다.
  5. PC용 학습 화면을 엽니다.

이 PC의 설치 경로는 실행 스크립트가 자동으로 찾아 사용합니다. 공개 페이지가 PC 화면을 여는 권한을 주지 않거나 PC 프로그램이 꺼져 있으면 위 주소를 새 탭에 직접 여세요.

PC 화면에서 완료하면

  1. 현재 기기의 답변 초안을 확인합니다.
  2. PC 연결 프로그램이 GitHub CLI로 공개 학습 Issue를 만듭니다.
  3. 연결 프로그램이 Claude/Codex CLI에 학습 자료·평가 기준·답변을 전달합니다.
  4. 리뷰를 같은 Issue 댓글로 저장합니다.
  5. 학습 기록을 새로고침하고 펼치면 답변과 리뷰를 다시 볼 수 있습니다.

휴대폰과 공개 페이지

공개 페이지는 PC 명령을 실행할 수 없습니다. 완료 버튼을 누르면 답변을 미리 채운 GitHub 새 Issue 화면으로 이어지고, 그 화면에서 생성 버튼을 눌러야 기록됩니다. 그 전까지는 저장된 것이 아닙니다.

답변이 길 때 · 링크에 담을 수 없을 만큼 길면 Markdown 파일을 내려받습니다. GitHub 새 학습 기록 화면을 열고 파일 내용 전체를 본문에 붙여 넣은 뒤 저장하세요. 파일 끝의 muse-submission 주석까지 그대로 두어야 리뷰가 연결됩니다.

PC가 꺼져 있으면 리뷰는 대기합니다. PC 연결 프로그램을 다시 켜면 남은 기록을 처리합니다. GitHub 저장 전의 초안은 다른 기기에 자동으로 공유되지 않습니다.

리뷰가 오지 않을 때

  • PC가 꺼져 있거나 절전 중이거나 인터넷이 끊겼으면 다시 켜질 때까지 대기합니다.
  • CLI 로그인이 만료되거나 사용 한도에 도달하면 답변은 보존되고 리뷰만 대기합니다. 실패한 리뷰는 시간을 두고 다시 시도합니다.
  • 답변을 수정하면 이전 리뷰는 그 답변의 리뷰가 아니므로 새 리뷰가 필요합니다.

PC 연결 화면의 학습 기록 상태와 콘솔 메시지를 확인하세요. 즉시 리뷰가 필요하면 답변 아래 ‘수동 리뷰 프롬프트’를 복사해 AI 대화에 전달할 수 있습니다.
